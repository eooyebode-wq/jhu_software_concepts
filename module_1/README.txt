Personal Flask Website - Module 1
===================================

Description
-----------
A personal website built with Flask, HTML, and CSS. It includes three pages:
Home (name, position, bio, and photo), Contact (email and LinkedIn), and
Projects (details about this Module 1 project and a link to its GitHub repo).

Requirements
------------
- Python 3.10 or higher

How to Run
----------
1. Open a terminal and navigate into this folder (module_1).

2. Install the required package:
   pip install -r requirements.txt

3. Start the server:
   python3 run.py (try this also if "python run.py" does not work)

4. Open a web browser and go to:
   http://localhost:8080

The site has three pages, they're all reachable from the navigation bar in the top-right
corner of every page:
   - Home:     http://localhost:8080/
   - Contact:  http://localhost:8080/contact
   - Projects: http://localhost:8080/projects

To stop the server, go back to the terminal and press Ctrl+C if using a Mac system.
